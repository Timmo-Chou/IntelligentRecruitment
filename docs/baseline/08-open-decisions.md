# 待确认事项与默认假设

## 1. 使用规则

- “必须确认”事项在相关功能开发前需要决策人给出结论。
- “联调前确认”可在 Mock 开发期间保持默认假设，但接入伙伴前必须冻结。
- “可后置”不阻塞 P0。
- 默认假设只是为了文档和 Mock 一致，不能替代产品确认。

## 2. 必须确认：产品与范围

| ID | 决策 | 当前默认假设 | 影响 |
|---|---|---|---|
| P-01 | P0 是内部 Demo 还是真实客户试用 | 按真实简历试用设计 | 安全、合规、文件、运维投入 |
| P-02 | 首批核心用户 | 企业 HR，兼容招聘顾问 | 导航、企业模型、权限 |
| P-03 | P0 是否启用多人团队 | **已确认：支持 Company/Workspace 两级成员；Workspace 为租户边界** | 权限、账单、UI |
| P-04 | AI 自动工作流是否进入 P0 | 不进入，只做引导式串联 | 页面、任务编排、费用 |
| P-05 | P0 面试题库范围 | 保存/回看题目包，不做完整题库管理 | 导航、数据模型 |
| P-06 | 对话历史范围 | 收敛为招聘任务列表和回看 | 页面和数据 |
| P-07 | 概览是否为默认首页 | 是 | 路由和新手流程 |

## 3. 必须确认：计费

| ID | 决策 | 当前默认假设 | 影响 |
|---|---|---|---|
| B-01 | 注册试用金额和有效期 | **已确认：个人实名一次30元；认证企业创建首个Workspace一次100元；均90天过期** | 登录、账本、文案 |
| B-02 | JD 生成价格 | 待定，执行前显示配置价格 | 产品闭环 |
| B-03 | 简历解析是否单独计费 | 暂并入筛选产品价 | 估算和结算 |
| B-04 | 简历筛选价格 | 按成功处理份数，具体单价待定 | 账本、部分成功 |
| B-05 | 面试题价格 | 按候选人/题包，具体单价待定 | 批量选择和预算 |
| B-06 | 免费额度与充值额度扣减顺序 | 先用即将过期/试用额度 | 钱包规则 |
| B-07 | Provider 失败、用户取消、重试收费 | 无成功产品结果不收结果费；基础费待定 | 补偿、文案 |
| B-08 | 部分成功收费 | 仅结算成功业务单位 | 筛选和面试题 |

## 4. 必须确认：招聘规则

| ID | 决策 | 当前默认假设 | 影响 |
|---|---|---|---|
| R-01 | 默认筛选维度和权重 | AI 建议，用户必须确认 | 方案和结果 |
| R-02 | 是否允许一票否决规则 | 允许合规业务条件，必须显式确认 | 公平性和评分 |
| R-03 | 缺失信息如何评分 | 标记未知，不默认扣为不合格 | 解释性 |
| R-04 | 分数等级阈值 | 90/80/70 仅作初始展示 | UI 和筛选 |
| R-05 | 是否自动为高分候选人出题 | 否，必须人工选择并确认费用 | 成本和决策 |
| R-06 | 人工修改 AI 结果如何保留 | 新业务版本并保留来源 | 数据和审计 |

## 5. 必须确认：文件、数据和合规

| ID | 决策 | 当前默认假设 | 影响 |
|---|---|---|---|
| D-01 | 文件格式、单文件大小和批量上限 | PDF/DOC/DOCX；具体限制待压测 | 上传和任务 |
| D-02 | 扫描 PDF/OCR | 至少识别并提示；是否 P0 OCR 待定 | 解析成功率 |
| D-03 | 恶意文件检测供应方 | 我方基础设施提供 | 上传安全 |
| D-04 | 候选人去重与多简历规则 | 先提示重复，不自动合并 | 人才模型 |
| D-05 | 候选人数据保留期 | 待业务/法务确认 | 删除、存储成本 |
| D-06 | 谁能查看完整 PII | P0 仅组织管理员/当前招聘人，需确认 | 权限和审计 |
| D-07 | 数据是否允许传外部模型/境外 | 默认不得，需部署与法务确认 | Provider 选择 |
| D-08 | 用户删除任务/候选人的语义 | 产品隐藏与永久删除分离 | 数据生命周期 |

## 6. 联调前确认：AI Platform

| ID | 决策 | 当前默认假设 | 影响 |
|---|---|---|---|
| A-01 | 服务认证 | 独立服务凭证，支持轮换 | HTTP Adapter |
| A-02 | Webhook 签名 | 时间戳 + Key ID + Body HMAC | 回调安全 |
| A-03 | 流式协议 | SSE 或 fetch streaming | 前端/业务服务 |
| A-04 | 回调失败重试和查询兜底 | 指数退避 + GET Task | 可靠性 |
| A-05 | 最大批量和并发 | 待伙伴容量评估 | 拆批和限流 |
| A-06 | 文件引用有效期 | 覆盖排队与执行时间，任务绑定 | 文件安全 |
| A-07 | 平台数据保留和删除 SLA | 临时处理，完成后尽快删除 | 合规 |
| A-08 | 语义召回由谁负责 | 待定；业务侧控制候选人范围 | 数据、pgvector |
| A-09 | Usage 成本币种和精度 | CNY 最小单位；跨币种待定 | 对账 |
| A-10 | 契约兼容和弃用周期 | V1 内向后兼容 | 双方发布 |

## 8. 可后置决策

- 微信登录。
- 团队共享余额或独立额度。
- 在线充值、优惠和发票。
- 完整帮助中心和工单。
- 完整面试题库分类和运营。
- 职位外部发布和 ATS 集成。
- 移动端、语音输入和成长体系。
- Elasticsearch/OpenSearch 和 Kubernetes。

## 9. 建议的决策顺序

1. 确认真实试用还是 Demo、首批用户和 P0 页面范围。
2. 确认计费单位、失败/取消/部分成功规则。
3. 确认文件限制、OCR、数据地域、保留和 PII 权限。
4. 与伙伴确认能力、Schema、认证、回调、批量和 SLA。
5. 确认生产云、验证码和认证方案。
6. 冻结 `Product Baseline V1` 和 `AI Contract V1` 后再搭建代码。
