# 通知中心设计（Phase 6 扩展）

## 目标
为登录用户提供站内通知列表、未读数、单条已读和全部已读能力。通知按用户隔离，不跨用户、企业或 Workspace 泄露业务内容。

## 交互
- 顶部铃铛显示未读红点，点击进入 `/notifications`。
- 通知页按时间倒序展示标题、正文、时间和可选跳转链接。
- 点击通知标记已读并跳转；支持“全部标为已读”。
- 空状态显示“暂无通知”，请求失败显示可重试错误。

## 事件
企业申请提交、企业加入申请提交/审批结果、AI 任务完成/失败、账单额度异常均可生成站内通知。当前已接入企业申请提交、加入申请提交及企业管理员审批结果；其余事件按相同模型扩展。

## API
`GET /notifications?limit=50`、`POST /notifications/{id}/read`、`POST /notifications/read-all`。
